# KamiLib(台服 fork)

由 MidoriKami 開發的 Dalamud 插件共用函式庫，提供角色設定檔管理（含「角色設定管理」視窗）、
指令管理、分頁視窗、道具／副本／區域等選擇清單視窗與 ImGui 輔助元件。

## 台服 fork 的目的

跟隨艦隊釘 API13（工作分支 `tc-dailyduty-api13-pin`），把介面繁中化、讓判定在台服資料上正確，
並修掉未登入或資料取不到時會讀空指標的路徑。上游沒有 README，這份是我方新寫的說明。

## 與上游的差異

- **介面繁體中文化**：設定管理器、選擇清單視窗、傳送與指令說明訊息、顏色設定的「預設」按鈕。
- **台服副本名判定**：`GetDutyType` 認得繁中副本名的「零式」與「極」。
- **「角色設定管理」視窗**：打開時不再洗掉各角色設定檔裡插件自己的設定；不再自動向 Lodestone
  查角色，要查請在視窗上勾選（預設關，只在這次載入期間有效）。
- **判空修正**：未登入時角色設定更新不再從位址 0 讀取、不再建立名為 `0` 的設定資料夾；
  無人島狀態取不到時當作不在島上。
- **其他修正**：`ColorEditWithDefault` 不再每幀觸發設定變更；選單視窗可從外部指定選取項目並切回清單分頁。
- **多處降低記憶體用量**：選項清單不再每幀重新配置與反射查詢；登入時讀過的角色設定檔沒變就不重讀磁碟。

## 誰在用它

目前 3 個插件 repo 以子模組使用：`DailyDuty`、`Mappy`、`SortaKinda`。
